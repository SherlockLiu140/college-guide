# 大学生生活指南

按性价比排序的在校生决策清单。**改编自 [eternity4719](https://github.com/eternity4719) 的[《高性价比人生指南》](https://github.com/eternity4719/HowToLiveBetter)（[在线阅读](https://eternity4719.github.io/HowToLiveBetter/)）**，采用与原作相同的 **[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)** 许可。

**10 节 80 条。A 级 47 条、B 级 12 条、C 级 7 条、D 级 14 条。**

每一条都回答两个问题：**花掉什么，换回什么。** 每条的字段一栏都不省——成本、说人话、收益、证据等级、来源、备注。

> **署名与修改说明见 [NOTICE.md](NOTICE.md)**（含逐条对照表：哪 14 条引用了原作、引用的是原著的哪一节哪一条）。原作仅覆盖成年人场景，本书换了人群和口径，并新增了原著完全没有的 10 个章节。

## 五种用法

| 形态 | 文件 | 适合 |
|---|---|---|
| **在线版** | `index.html` | 日常查。左侧固定目录，按关键词／章节／证据等级／成本维度筛选，条目互相指路 |
| **离线单文件** | `dist/大学生生活指南-离线版.html` | 发给别人。整本连检索和筛选都在这一个文件里，**双击就开、不用联网、微信能直接传** |
| **PDF** | `dist/大学生生活指南.pdf` | 打印或在平板／电脑上通读。A4，约 52 页，**带页码目录和 PDF 书签**，每节另起一页 |
| **EPUB** | `dist/大学生生活指南.epub` | Kindle 或其他阅读器。用 Send to Kindle 发过去就行 |
| **让 AI 照书回答** | `skills/college-guide/` | 直接问「大一要不要进学生会」「实习被安排上夜班怎么办」。它会先查条目再答，并注明出自第几节第几条 |

在线版页面顶部的「其他格式」那一排，就是后三种的下载入口。

### 在线版怎么打开

```bash
python3 -m http.server 8000
```

然后浏览器打开 `http://localhost:8000/`。

> `index.html` 必须经 http 打开。直接双击本地文件会空白，因为浏览器不许网页读本地文件——那种场景请用离线单文件版。

### 想发到 GitHub Pages

仓库里带了一个 workflow（`.github/workflows/build.yml`）。推到 `main` 后它会：

1. 装中文字体和 reportlab
2. 跑 `node tools/build-all.mjs`，**先做一致性检查**（网页解析器和工具解析器必须逐字段一致，不一致直接失败）
3. 把三种格式作为构建产物传上去，供下载
4. 把整站（`index.html` + `book/` + `dist/`）发到 GitHub Pages

**只需要在仓库 Settings → Pages 里把 Source 设成 GitHub Actions，设一次就行。** 之后正文一改就自动重建重发。

## 怎么读

界面是**左侧固定目录 + 右侧正文**，正文按章节分组，读起来像书而不是卡片流。

- **目录在左栏。** 10 节列在里面，每节后面是当前命中的条数。点节名就跳过去，同时展开这一节的条目清单；滚动时目录会自动高亮你所在的节，并跟着展开。筛掉的节会变灰。
- **不用全做。** 这是一份按性价比排好的备选单，不是任务清单，挑走一两条就算数。
- **四个快捷入口**（左栏第二组）：
  - **只想看最省力的** → 7 条，既不花钱、不花时间、不需要毅力，收益又落在最大一档（PDF 和 EPUB 里是附录一）
  - **只看证据最硬的** → 47 条 A 级
  - **只看证据边界（D）** → 14 条没有直接证据的条目，**每一条都在备注里写明了为什么只到 D**（附录三）。这是这本书和普通攻略最大的区别：它告诉你自己不靠谱的地方在哪
  - **只看红线（安全口径）** → 18 条后果涉及学籍、刑事、人身安全的条目（附录二）
- **想自己组合**，用下面的筛选器：证据等级、花钱、花时间、要毅力、收益、换回什么（口径）。几个维度可以叠着用，左栏目录的条数会跟着变。
- **搜索**在顶栏，随时可用；按 `⌘K` / `Ctrl+K` 直接聚焦。
- **条目之间会互相指路**（「见本节第 5 条」这种）。点一下直接跳过去、自动展开并高亮。在 PDF 和 EPUB 里这些指路是可以点的真链接。标注「原书」的是从原著迁移来的条目，不在本书内，点了不会跳。
- **来源默认折叠**，点「来源 展开出处」看引文和链接——不占视线，但一点就有。
- **高职和本科路径有分歧的地方**，在条目里单列了「路径」一栏（共 7 处）。

## 条目长什么样

每条都写全这几栏，一栏都不省：

```markdown
### 3. 上自习和上课时，把手机放到手够不到的地方
<!-- 成本标签: 钱=0 时间=0 毅力=些 收益=中 口径=学业 -->
- 成本：不花钱。每次坐下多花 5 秒把手机放进包里或抽屉里。
- 说人话：手机只要在你旁边的桌上、哪怕关着机、哪怕你没碰它，你的脑子就有一部分在替它值班…
- 收益：Ward 等人做了一组实验…差异在需要持续注意的任务上显著。
- 路径：（高职 / 本科有分歧时才出现）
- 证据等级：B
- 来源：Ward AF, Duke K, Gneezy A, Bos MW (2017). Brain Drain… <https://doi.org/10.1086/691462>
- 备注：给 B 的原因：这是实验室研究，测的是当次任务的认知容量，不是一学期后的成绩或绩点…
```

**成本标签**（那行 HTML 注释）是给检索页用的元数据：钱（0/少/中/大）、时间（0/少/中/大）、毅力（否/些/是）、收益（负/小/中/大）、口径（时间/学业/安全/钱/就业/健康）。**取值域必须保持一致**，否则筛选器会漏。

## 证据等级怎么定

本指南沿用原著的 A/B/C 三级，**新增 D 级**——因为「该不该进学生会」这类问题没有随机对照试验，硬标 A 级就是造假，而那会毁掉这本书唯一值钱的东西。

| 等级 | 含义 |
|---|---|
| **A** | 有具体数字，来自随机试验、荟萃分析或官方文件 |
| **B** | 有具体数字，但来自单项观察性研究或官方统计 |
| **C** | 有明文规定或公开数据，但没有量化效果 |
| **D** | **没有直接证据**，来自明文规定或公开共识，**并必须在备注里写明为什么只到 D** |

一句话里有两层不同强度的结论时，会分成两个等级写（例如「A（法条存在）/ C（高发这一判断）」），全书共 7 处。

两条铁规矩：

1. **不编数字。** 每个写进条目的政策数字都先查过原始出处。查不到出处的，就在备注里标「待核实」并说明不引这个数。
2. **承认边界。** D 级条目不给文献，并在备注里明写「找不到研究」。原著「给 B 的原因」这个传统，是这本书最该继承的东西。

## 构建

```bash
node tools/build-all.mjs            # 全部格式
node tools/build-all.mjs --no-pdf   # 跳过 PDF（不需要装 reportlab）
```

PDF 需要 Python 的 reportlab：

```bash
pip install reportlab
```

构建脚本会自动找中文字体，macOS / Linux / Windows 都能跑。Linux 上如果报找不到字体，`apt-get install -y fonts-noto-cjk` 即可。

### 三条构建上的约定

**一、解析逻辑只有一份，且有一致性检查兜底。**
`tools/lib/book.mjs` 是工具侧的解析器，`index.html` 里有一份等价的浏览器端实现（页面要能独立运行，所以不能共用文件）。`build-all.mjs` 每次构建前会把两边在真实正文上跑一遍、**逐字段比对 80 条**，不一致直接失败。这一道检查拦的是最阴的一类 bug：网页上看到的和电子书里印出来的不是同一批内容。

**二、数据中转。**
`build-data.mjs` 先把正文规范化成 `dist/book.json`，EPUB 和 PDF 都吃这一份。所以电子书和纸质版的条目、顺序、字段必然一致。

**三、构建脚本的替换锚点是硬校验的。**
改 `index.html` 结构导致 `build-offline.mjs` 的锚点失效时，脚本会直接报错，不会静默产出一个「页脚还是在线版文案」的坏文件。

### 改完正文之后

```bash
node tools/build-all.mjs
```

在线版会立刻反映改动（页面直接读 `book/`，刷新即可）。另外三种格式要重新生成。

## 已知限制

- PDF 里有个别行会把句号或顿号挤到下一行行首（约 52 页里 2 处）。原因是 reportlab 的中文断行对「恰好排满一行」的取舍，不是内容问题。
- EPUB 的排版由阅读器决定，各设备观感不同；样式只做了字体、缩进和分隔线这类最小干预。
- 离线单文件版是快照，不会随正文自动更新。

## 和原著的关系

原著的场景是成年人（口径为死亡率／金钱／人身自由），本书的场景是在校生（口径为时间／学业／钱／就业／安全／健康），所以：

- **迁移**：条目保留原著的数据和结论，注明迁移自第几节第几条。典型来源是第 23 节（学什么技能划算）、第 24 节（看病）、第 1 节（头盔安全带）、第 5 节（不要浪费钱）、第 9 节（法律红线）、第 14 节（账号与信息安全）、第 30 节（上学以后的孩子）。
- **改写口径**：结论在，但成本栏和收益栏换算成在校生的场景。
- **新增**：原著整块没有的内容——上课与听课、四六级、考驾照、学生会社团、实习与劳动权益（《职业学校学生实习管理规定》那一整套）、学生医保、奖助学金与助学贷款。

## 下一批可以加什么

这一批 10 节是 MVP。按性价比排序，下一批值得做的方向：

1. **毕业去向**（专升本 / 考研 / 就业 / 参军，四条路的算账与时间线）
2. **竞赛与科研**（哪些赛事在本校算数、怎么找指导老师）
3. **转专业、辅修与学分认定**（教务规则的实际操作）
4. **恋爱与性健康**（原著第 10 节的迁移 + 校园场景改写）
5. **心理与危机**（扩展到求助路径、请假与休学的流程）
6. **租房与校外住宿**（原著第 15 节的迁移）
7. **维权与申诉**（学生申诉三个时限的完整操作流程）

新增条目时请保持条目格式完整，并且**每条 D 级都要在备注里写明为什么只到 D**。
